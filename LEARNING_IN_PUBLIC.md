#BuiltToday

I built a hotel booking cancellation model for Machine Learning Zoomcamp 2026. It ranks reservations using only fields that do not reveal the final reservation status, compares logistic regression, trees, a random forest, and gradient boosting on a time-based split, and serves the saved model with FastAPI and Docker. On the later test period the selected model reached ROC AUC 0.826.
